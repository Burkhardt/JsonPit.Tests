# JsonPit.Tests

This repository is archived and kept for historical reference.

The JsonPit test suite no longer lives in a separate repository.

It now continues here:

- Package-owned tests: `JsonPit/JsonPit.Tests` in the `JsonPit` repository
- Cross-library integration workspace: `RAIkeep`

Current repositories:

- JsonPit: https://github.com/Burkhardt/JsonPit
- RAIkeep: https://github.com/Burkhardt/RAIkeep

Reason for the change:

- keep JsonPit tests with the JsonPit code they validate
- use RAIkeep as the umbrella workspace for integration across JsonPit, OsLib, RaiUtils, and RaiImage
- preserve this repository only as historical reference
